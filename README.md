## Project Overview

GridBalance is a smart building energy dashboard prototype for commercial real-estate operations. The interface helps facility teams monitor HVAC consumption, solar generation, building load, alerts, sustainability impact, automation rules, and AI-based load-balancing recommendations.

The project is designed as a polished UI/UX prototype that demonstrates how a commercial building owner or facility manager could understand energy performance and take quick operational actions from one dashboard.

## Technology Used

- HTML
- CSS
- Vanilla JavaScript

This project does not use React, Next.js, or Tailwind CSS. It is intentionally built as a lightweight standalone web prototype that can run directly in a browser.

## How to Run

Open `index.html` in any modern browser.

No installation, build command, or server is required.

## Main Features

- Role-based login mockup with auto-filled demo credentials
- Overview dashboard with portfolio KPIs
- Building portfolio section
- Energy analytics with filters and export actions
- HVAC management with setpoint controls
- Solar generation dashboard
- AI load balancer recommendations
- Automation rule management
- Alerts and issue resolution workflow
- Sustainability metrics and impact summary
- Report generation mockup
- Settings and profile-related flows

## Design Notes

This is a single-page application style prototype. The sidebar navigation switches between sections inside `index.html` instead of loading separate HTML pages. Each section, such as `overview`, `solar`, `hvac`, and `balancer`, represents one page view in the dashboard.
